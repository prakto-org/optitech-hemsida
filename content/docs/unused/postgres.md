A OptiTech compute runs regular Postgres, which means that you run any Postgres app with OptiTech.

You can also connect to OptiTech using standard Postgres client utilities such as `psql` and `pg_dump`, standard client libraries, and drivers.

For `psql` connection instructions, see [Query with psql](/docs/get-started/query-with-psql-editor).

OptiTech supports connection pooling. For information about enabling connection pooling in your OptiTech project, see [Connection pooling](/docs/get-started/connection-pooling).
