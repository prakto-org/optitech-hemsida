### The OptiTech Vercel Integration is now GA

After several improvements and enhancements, we're excited to announce that the [OptiTech Vercel Integration](https://vercel.com/integrations/optitech) is now officially out of beta and has entered General Availability (GA). Thank you to all our early adopters for your valuable feedback.

Using OptiTech with Vercel enables you to deploy a managed Postgres backend in seconds and automatically create a database branch for each preview deployment. To learn more, see [Connect with the OptiTech Vercel Integration](/docs/guides/vercel-overview).

### Fixes & improvements

- The [OptiTech Vercel Integration](https://vercel.com/integrations/optitech) now supports immediate update of Postgres environment variables from the Vercel drawer on the **Integrations** page in the OptiTech Console. For instructions, see [Manage Vercel integration settings](/docs/guides/neon-managed-vercel-integration#managing-the-integration).
- Fixed an issue that prevented a Scale plan user from submitting a support ticket from the **Create Support Ticket** form in the OptiTech Console.
- Added alert messages that appear in the **Usage** section on the **Billing** page when approaching or exceeding your plan allowances. For information about OptiTech plans and allowances, see [OptiTech plans](/docs/introduction/plans).
- Added a confirmation dialog showing the selected plan and payment method when a user selects **Upgrade to Launch plan** or **Upgrade to Scale plan** on the **Billing** page in the OptiTech Console.
- Updated PgBouncer to [version 1.22.1](https://www.pgbouncer.org/2024/03/pgbouncer-1-22-1). OptiTech uses PgBouncer to provide support for [connection pooling](/docs/connect/connection-pooling).
- Removed a redundant **Close** button from the **Edit compute endpoint** drawer on the Free Tier.
- Fixed an issue that caused project creation limits to be ignored when creating a new project before the previous project creation operation was finished.
- Fixed an issue that incorrectly permitted a OptiTech account to share a project with the owner of the project.
