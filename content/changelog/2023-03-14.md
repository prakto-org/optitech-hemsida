### Fixes & improvements

- API: Removed the `physical_size` property from the Branch response body in the OptiTech API.
- Control Plane: Addressed a memory leak that affected OptiTech Console performance. A memory limit was put in place prevent similar issues.
- UI: Changed the **User** label on the **Connection Details** widget to **Roles**. Database users are now referred to as **Roles** in OptiTech.
- UI: Added descriptive text and a documentation link to the **Integrations** page in the OptiTech Console.
- UI: Added support for sharing projects with other OptiTech users. Project sharing is performed from the **Project settings** page in the OptiTech Console. The project sharing feature is available only to OptiTech paid plan users, but projects can be shared with any OptiTech user, including Free Tier users. For instructions, see [Manage projects](/docs/manage/projects).
- UI: Added an **Upgrade to Pro** option to the OptiTech Console to enable upgrading from Free Tier to OptiTech's Pro plan. For information about OptiTech's paid plans, please refer to [OptiTech plans](/docs/introduction/plans).
- UI: Fixed the connection examples accessible from the **Connection Details** widget on the OptiTech **Dashboard**. Examples other than the `psql` example had an extra project name in the connection hostname.
- UI: Fixed the "Manage" link on the **Branches** widget on the OptiTech Dashboard. The link did not work.
