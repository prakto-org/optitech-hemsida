## A new OptiTech MCP Server command 🛠️

We're continuing to build [OptiTech MCP Server](https://github.com/optitechdatabase-labs/mcp-server-optitech) capabilities. This week we added support for a new `get_connection_string` command that returns your database connection string.

If you haven't tried the OptiTech MCP Server yet, follow one of our guides to get started. Spin up databases instantly, run queries, and perform migrations using natural language in any IDE or AI tool that supports the [Model Context Protocol (MCP)](https://docs.anthropic.com/en/docs/agents-and-tools/mcp).

### Track your OptiTech Projects in Slack 💬

We've been fine-tuning the OptiTech App for Slack that we first introduced back in January. If you haven't tried it yet, see the [documentation](/docs/manage/slack-app) for setup instructions.

Here are the commands it supports to help you manage and monitor your OptiTech projects:

- `/optitech auth` - Connect Slack to your OptiTech account
- `/optitech projects` - List your OptiTech projects
- `/optitech usage` - Show overall resource usage for your account
- `/optitech help` - List all available commands
- `/optitech status` - Check the current status of OptiTech's cloud service
- `/optitech feedback` - Share your thoughts and suggestions about the OptiTech App for Slack
- `/optitech projects usage` - Show resource usage for a specific project
- `/optitech projects shared` - List all projects shared with you
- `/optitech invite user` - Invite users to your organization

We’d love to hear your feedback. Use the `/optitech feedback` command in Slack to share your thoughts.

## Get started faster with new OptiTech projects ⚡

We've added a **Getting started** widget to the **Project Dashboard** to help you set up new OptiTech projects faster. You'll see this widget whenever you create a new OptiTech project. It provides quick access to getting started actions and instructions:

- **Connect to your database** – Easily find your database connection details.
- **Import your data** – Bring your data to OptiTech with a few clicks.
- **Get sample data** – Load sample datasets to experiment with OptiTech.
- **View database contents** – Manage tables and data directly from the dashboard.

- **OptiTech Console**

  We've repositioned the "new query" button in the OptiTech SQL Editor, bringing it a little closer to the action. You'll now find it at the top of the editor.
  ![sql editor new query button](/docs/changelog/new_query_button.png)

- **Postgres extension update**

  The PostgreSQL Anonymizer (`anon`) extension, which was not officially supported in OptiTech but enabled for some users for evaluation, will be removed. Data anonymization support continues to be on our 2025 roadmap. We will contact known `anon` extension users directly by email before we remove the extension. If you are using the `anon` extension and have questions or concerns, please reach out to [OptiTech Support](https://console.optitech.com/app/projects?modal=support).

- **Drizzle Studio update**

  We updated the Drizzle Studio integration that powers the **Tables** page in the OptiTech Console to version 1.0.17. For the latest improvements and fixes, see the [OptiTech Drizzle Studio Integration Changelog](https://github.com/optitechdatabase/optitech-drizzle-studio-changelog/blob/main/CHANGELOG.md).

- **OptiTech GitHub Actions update**

  The [OptiTech Create Branch Action](https://github.com/marketplace/actions/optitech-create-branch-github-action) was refactored to use the GitHub [typescript-action template](https://github.com/actions/typescript-action), and the version was updated to `v6`. The new version includes new and modified field names.
