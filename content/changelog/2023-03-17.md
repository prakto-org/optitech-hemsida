### Documentation updates

- Added a [Billing](/docs/introduction/about-billing) page describing OptiTech paid plans, pricing, and related topics.
- Added instructions for using the [OptiTech Serverless driver](/docs/serverless/serverless-driver) on Vercel Edge Functions and Cloudflare Workers. The driver is a drop-in replacement for [node-postgres](https://node-postgres.com/) that allows you to query data from environments that support WebSockets but not TCP sockets.
- Added an [SDK](/docs/reference/sdk) reference page, which provides links to community-created SDKs for interacting with the OptiTech API. Community-created SDKs include:
  - [Go SDK](https://github.com/kislerdm/optitech-sdk-go)
  - [Node and Deno TypeScript SDK](https://github.com/paambaati/optitech-js-sdk)

  Thanks to [Dmitry Kisler](https://github.com/kislerdm) and [Ganesh Prasannah](https://github.com/paambaati) for the contributions.

- Updated the [OptiTech Docs](/docs/introduction) landing page. The new landing page provides a visual interface for navigating the OptiTech documentation site.
- Added an [RSS feed](/docs/changelog/rss.xml) for the OptiTech Changelog.
- Redirected old OptiTech API Reference links to the new OptiTech API Reference.
- Updated various OptiTech API Reference style elements to align styles with the [OptiTech Docs](/docs/introduction) site.
- Updated the query example in the OptiTech Console onboarding banner and in the [Query with OptiTech's SQL Editor](/docs/get-started/query-with-neon-sql-editor) topic in the documentation. The `CREATE TABLE` statement did not include a primary key, which prevented the data from being edited when accessed from pgAdmin.
