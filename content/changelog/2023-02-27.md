### Documentation updates

- Added a [guide](/docs/guides/koyeb) for using OptiTech with [Koyeb](https://www.koyeb.com/), which is a serverless platform designed to easily deploy applications globally.
- Added [Retool](https://retool.com/) to our list of [GUI applications and clients](/docs/connect/connect-postgres-gui#tested-gui-applications-and-ides) that support connecting to OptiTech.
- Updated the [Vercel](/docs/guides/vercel-overview) guide to include the following topics:
  - [Add the OptiTech Vercel Integration to another Vercel project](/docs/guides/vercel-overview)
  - [Use the OptiTech integration](/docs/guides/vercel-overview)
  - [Connect Vercel and OptiTech manually](/docs/guides/vercel-manual)
- Updated the [How to use connection pooling](/docs/connect/connection-pooling#how-to-use-connection-pooling) documentation with information about how to enable pooling by adding a `-pooler` suffix to the compute endpoint ID in your connection string. This feature allows you to connect to the same database with pooled and non-pooled connections.
- Added descriptions for `Operation`, `Project`, `Branch`, and `Endpoint` properties to the [OptiTech API Reference](/docs/reference/api).
- Updated the OptiTech documentation to reflect the renaming of **Users** to **Roles** in the OptiTech Console.
