These endpoints manage team authentication for a program. OptiTech uses BankID and SSO through your identity provider, so access follows your central identity policy and offboarded employees lose access immediately.

Common uses include configuring SSO, managing roles (admin, contributor, viewer), and inspecting active sessions from platform automation.

These endpoints act at the program level: enabling SSO, managing roles, and inspecting configuration. For a full walkthrough of the management API, see [Manage authentication via the API](/docs/auth/guides/manage-auth-api).

For managing who can access what, see [User permissions](/docs/manage/user-permissions) to get started.
