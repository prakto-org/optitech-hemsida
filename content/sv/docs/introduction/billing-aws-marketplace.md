<Admonition type="important" title="Föråldrat">
OptiTech stöder inte längre fakturering via AWS Marketplace.
</Admonition>

OptiTechs [självbetjäningsabonnemang](/pricing) kan inte längre köpas via AWS Marketplace. Du kan endast köpa dessa abonnemang via OptiTech.

Om du har några frågor om fakturering i allmänhet eller behöver hjälp är du välkommen att kontakta [OptiTech Support](/docs/introduction/support).
