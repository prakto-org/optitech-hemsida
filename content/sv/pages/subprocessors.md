Senast uppdaterad: 16 april 2026

För att kunna tillhandahålla våra tjänster kan OptiTech, LLC. anlita och använda databehandlare som har tillgång till vissa kunduppgifter. På denna sida finns viktig information om varje underleverantörs identitet, verksamhetsort och roll.

Denna sida om underleverantörer ingår i det [databehandlingsavtal (DPA)](https://optitech.com/dpa) och [de användarvillkor](https://optitech.com/terms-of-service) eller det huvudavtal (MSA) som ingåtts mellan kunden och OptiTech (beroende på vilket som är tillämpligt).

## Uppdateringar av denna sida 

På grund av karaktären hos vår globala verksamhet och våra kontinuerliga ansträngningar att göra våra kunder nöjda kan våra affärsbehov och tjänsteleverantörer komma att ändras från tid till annan. Vi kan till exempel fasa ut en tjänsteleverantör för att konsolidera och minimera vår användning av tjänsteleverantörer. På samma sätt kan vi lägga till en tjänsteleverantör om vi anser att detta kommer att förbättra vår förmåga att leverera våra tjänster.

Du kan prenumerera på meddelanden via e-post om vi lägger till eller byter ut underleverantörer genom att klicka här:

[Prenumerera på uppdateringar](https://optitech.com/subscribe-to-subprocessors)

Vi kommer endast att använda de uppgifter du lämnar i detta formulär för att behandla din begäran om information om vår lista över underleverantörer enligt vårt [databehandlingsavtal (DPA)](https://optitech.com/dpa) samt för att tillhandahålla de OptiTech-tjänster som du har tecknat. För mer information om hur OptiTech skyddar dina uppgifter, se vår [integritetspolicy](https://optitech.com/privacy-policy). 

OptiTech kan använda följande underleverantörer för att tillhandahålla tjänsterna till dig:

| Leverantörens namn         | Plats      | Syfte                         |
| ------------------- | ------------- | ------------------------------- |
| Salesforce          | USA | Programvara för kundservice       |
| Grafana             | USA | Leverantör av infrastrukturtjänster |
| Amazon Web Services | USA | Leverantör av infrastrukturtjänster |
| Microsoft Azure     | USA | Leverantör av infrastrukturtjänster |
