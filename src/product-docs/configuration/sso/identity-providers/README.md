# Identity providers

{% hint style="success" %}
You can log into OptiTech with any identity provider (IdP), given that it supports either SAML or OpenID Connect (OIDC).
{% endhint %}

Don't find documentation on how to set up SSO with your identity provider? Reach out to OptiTech support at [info@optitech-sverige.se](mailto:info@optitech-sverige.se) and we'll help you get set up.
